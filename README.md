# Correllia CPI Inflation Forecast — Pilot Demo

A Streamlit demo of an LSTM model that forecasts U.S. CPI (`CPIAUCSL`) 1, 2, and 3 months
ahead from FRED-MD macroeconomic data. Includes a track record against held-out test data,
a multi-fold walk-forward backtest vs. a naive baseline, and the option to upload your own
FRED-MD-formatted CSV to generate a custom projection.

## Running the demo

**Requirements:** Python 3.10+

1. Clone the repo and enter it:

   ```bash
   git clone <this-repo-url>
   cd correllia-cpi-inflation-pilot
   ```

2. (Recommended) create a virtual environment:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Launch the app:

   ```bash
   streamlit run app.py
   ```

   Streamlit will print a local URL (usually `http://localhost:8501`) and open it in your
   browser. A trained model (`cpi_lstm_model.pt`) and its supporting artifacts are already
   included in this repo, so the app runs immediately — no training step required.

## Uploading your own data

The app accepts a CSV formatted like the training data (`fred-md.csv`): a `sasdate` column,
a `CPIAUCSL` column, and the feature columns the model was trained on (listed in the app's
"What does the CSV need to look like?" expander), with at least 25 months of rows. Upload one
via the file picker at the top of the app to get a projection from your own data instead of
the bundled dataset — the rest of the page (track record, backtest, feature importances)
stays based on the model's original training/validation run.

## Retraining the model

To retrain from scratch (e.g. on updated FRED-MD data):

```bash
python cpi_lstm_v4.py
```

This overwrites `cpi_lstm_model.pt` and regenerates `predictions_test.csv`,
`feature_importances.csv`, and `walk_forward_results.csv`, which the app reads directly.
Restart the Streamlit app afterward to pick up the new model.

## Project layout

- `cpi_lstm_v4.py` — data prep, feature selection, LSTM model, training, and walk-forward
  backtest. Also defines the shared config (paths, sequence length, horizons).
- `cpi_inference.py` — loads the saved model and runs inference on the most recent window
  of data (bundled or uploaded) to produce a forecast.
- `app.py` — the Streamlit UI.
- `fred-md.csv` — training data snapshot.
- `cpi_lstm_model.pt`, `predictions_test.csv`, `feature_importances.csv`,
  `walk_forward_results.csv` — model weights and evaluation artifacts the app reads.

## Disclaimer

This is a pilot demo for evaluation purposes only. Forecasts are generated by a model
trained on historical data and are not investment or economic advice.
